\# Local Git states



\## Рабочая папка (working directory)



Это папка на компьютере, где лежат мои файлы. Я их вижу, открываю

и редактирую. Git замечает изменения, но пока не считает их

готовыми к коммиту — пока я не скажу ему об этом через git add.



\## Индекс (index / staging area)



Это промежуточная область внутри Git. Сюда попадают изменения

после команды git add. То есть индекс — это «корзина», куда

я складываю то, что хочу зафиксировать в следующем коммите.



\## Коммит (commit)



Это сохранённый снимок содержимого индекса — с автором, датой

и сообщением. Он остаётся в истории репозитория навсегда,

даже если потом удалить файл из рабочей папки.





\## Git vs GitHub



Git — это система контроля версий, работает локально на моём компьютере.

GitHub — это веб-сервис для хранения Git-репозиториев в интернете.

Git может работать без GitHub, но GitHub без Git не имеет смысла.



\## Использованные команды



\- git status — показывает состояние рабочей папки и индекса:

&#x20; какие файлы изменены, какие подготовлены к коммиту.

\- git diff — показывает разницу между рабочей папкой и индексом

&#x20; (что изменено, но ещё не добавлено).

\- git diff --staged — показывает разницу между индексом и последним

&#x20; коммитом (что уже подготовлено к коммиту).
