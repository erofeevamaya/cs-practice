2\. Сравнение версий и поиск изменений

git log --oneline --stat

Показывает историю коммитов в сокращённом виде. К каждому коммиту добавляется статистика изменений: какие файлы были изменены и сколько строк было добавлено или удалено.



git diff HEAD\~2 HEAD -- lab03/calc.py

Показывает различия между двумя состояниями calc.py: версией два коммита назад и текущей версией.



git show HEAD\~1

Показывает содержимое конкретного коммита, включая информацию о коммите и diff внесённых изменений.



Разница между git diff, git show и git log



git diff предназначен для непосредственного сравнения состояний и показывает изменения между ними.



git show показывает один конкретный объект Git, обычно коммит, вместе с его метаданными и изменениями.

git log предназначен для просмотра истории коммитов. Он позволяет узнать, какие коммиты были сделаны и в каком порядке.

Таким образом, diff отвечает на вопрос «что изменилось между двумя состояниями», show — «что было сделано в конкретном коммите», а log — «какая история изменений проекта».



git log -S"def" --oneline -- lab03/calc.py

Команда ищет коммиты, в которых изменилось количество вхождений строки def в calc.py.

В данной версии калькулятора def не используется, поэтому команда не нашла соответствующих изменений. Это показывает, что git log -S удобно использовать для поиска момента появления или удаления конкретного фрагмента текста.



git blame lab03/calc.py

Показывает для каждой строки файла коммит, в котором она появилась или была изменена, а также автора и другую информацию о коммите.

Для calc.py с помощью blame можно определить, в каком из трёх коммитов появились строки сложения, вычитания и умножения.



3\. Вывод

В ходе работы были созданы три последовательных состояния проекта и отдельные коммиты для каждого изменения. С помощью git diff можно сравнивать версии, git show позволяет подробно изучать отдельный коммит, git log — историю проекта, git log -S — искать изменения конкретного текста, а git blame — определять происхождение отдельных строк.
